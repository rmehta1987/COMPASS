# COMPASS — code and documentation

**Two trees, one public repository, one rule.** The rule: the survey instrument
is never tracked here, in any form. This repository is public.

| tree | where | what |
|---|---|---|
| Pipeline mirror | `agent/` `env/` `generate/` `benchmark/` `mcp/` `tests/` `curated/` `docs/`, `build.py` `checks.py` `build_targets.py` `encode_and_score.py`, `AGENTS.md` `DESIGN.md` `TASKS.md` `CHANGELOG.md` `COMPASS.md`, `arm_hybrid_e_D.md` | The specifier pipeline and its arm C16/D/E/hybrid measurement reports. Published from an orphan branch on 2026-09-03 so no codebook-bearing history is reachable from it. |
| Retrieval experiments | `src/`, `deploy/`, `RESULTS.md` `CHARACTERISATION.md` `FUSION.md` `QUERY_EXPANSION.md` `BRIEF_*.md`, tracked artifacts under `out/` | The frozen and fine-tuned embedding retriever measured on the Spark (Arm, GB10), its CPU deployment bundle, and the acceptance test that proves the bundle on another machine. |

Merged 2026-09-03. Where the two trees name the same thing differently:

- `build.py` is the pipeline's **dictionary** builder (raw codebooks to
  `build/dictionary.json`, version hash `3dc8415eccfe`). Every retrieval report's
  "`build.py` at `3dc8415eccfe` unchanged" refers to that hash.
- `build_targets.py` is arm E's target builder (1,352 targets). The retrieval
  work's `src/compass_build.py` emits 1,353; the one extra is `m2:Q785~2`, a
  free-text companion row (`RESULTS.md` §1).
- `encode_and_score.py` is arm E's frozen-encoder driver, kept byte-identical to
  the one that produced `arm_e.medcpt_a.json`. The retrieval work's
  `src/compass_score.py` supersedes it for everything in `RESULTS.md`.
- `arm_hybrid_e_D.md` §6 argued fine-tuning was unpromising; `RESULTS.md` §4 then
  measured it at +0.192 R@1. The pipeline report carries a dated note at that
  point rather than a silent edit.

## The deployed retriever

`deploy/` is the fine-tuned `bge-small` retriever: argmax cosine over 1,353
precomputed target vectors, CPU-only, no LLM call. `deploy/manifest.json`
records every convention (query prefix, CLS pooling, fp32, thread count,
abstention threshold) and the sha256 of every shipped file; `deploy/retriever.py`
asserts them at load and raises rather than warns. `deploy/smoke_test.py` proves
a port: it exits 0 only if the 224-row fixture reproduces R@1 0.567 without the
template and 0.643 with it, to the digit, on the machine it runs on. Both the
Spark and the x86 serving machine pass (`out/smoke_report_*.json`).

Two files the bundle needs are not tracked and must be copied from the training
machine (step 0 of the smoke test says how): `deploy/model/` (133 MB, over
GitHub's file limit) and `deploy/targets.json` (the question wording).

## What is withheld, and why

| withheld | reason |
|---|---|
| `module_{1,2,3}_codebook_full.csv`, `raw/`, `dictionary.json` | The COMPASS survey instrument: 3,222 codebook lines of question wording, including direct-identifier items (name, phone, email, address). Not cleared for public release. |
| `build/` | The instrument in JSON form, generated by `build.py`. Hash `3dc8415eccfe`. |
| `benchmark/fixtures/`, `retrieval_queries.json`, `fixtures/negative_requests.json` | Fixtures storing gold item wording verbatim. |
| `targets.json`, `deploy/targets.json`, `out/targets_*.json`, `arm_e*.json` | Selection targets and per-row results carrying stem and option wording. |
| `out/fusion_task1_overlap.json`, `out/qx_task2_paired.json`, `out/qx_task3_abstention.json` | Per-row retrieval artifacts that quote gold stems. Their figures are in `FUSION.md` and `QUERY_EXPANSION.md`; they regenerate from `src/`. |
| `run/`, `runs/`, `out/` otherwise | Run records, tool logs, checkpoints and score artifacts. |
| `benchmark/prevalence_key.py` | The held-out answer key for outcome prevalence. |
| `tests/resolver_eval_v2.jsx` | A browser harness with ~508 candidate wordings frozen inline. |
| `deploy/model/` | 133 MB fine-tuned checkpoint, over GitHub's file limit; not wording. |

**Consequence:** a fresh clone cannot build the dictionary, cannot run the
retrieval or resolver evaluations, cannot import the five `benchmark/` modules
that read the withheld key, and cannot re-freeze `deploy/`. It can run the
deployed retriever and its acceptance test once the two files above are copied.

**Residual, measured on this tree:** 169 distinct eight-word runs of instrument
wording across 20 files, scanned against `dictionary.json` on 2026-09-03. The
largest are `build.py` (45, its own parsing rules and assertions),
`CHARACTERISATION.md` (17, quoted example stems), `out/qx_preregistration.json`
(15, the smoke test's fixture: option labels used as template instances) and
`agent/schema.py` (15). They are fragments in docstrings, examples and pinned
fixtures, not the instrument.
